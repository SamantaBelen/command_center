# Home/Life 🟣

Espejo del área **Home/Life** de Notion (Workout Tracker, Grocery Shopping).

## Sistemas activos
- `grocery-images/` — recorta capturas de carrito (Instacart/Publix) en una
  imagen por producto y las sube a la página correspondiente en la base
  `Grocery Shopping`, con todos los campos llenos (Category, Store, Status,
  Quantity, Notes, Duración típica).

## Futuros candidatos
- Tracker de closet con NFC/UHF RFID.
